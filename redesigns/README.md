# Junkanoo redesign concepts

Three neo-brutal, Junkanoo-inspired directions for the WhatsApp AI receptionist
landing page. Each is a standalone static page sharing `kit.js` (scripted demo
receptionist, ROI formulas matching `js/roi.js`, and sample message traffic).

| Page | Direction | Interactive models |
|---|---|---|
| `rush-out.html` | Bay Street parade, flag aqua/gold/black | Live booking chat · 24h night-shift scrubber · ROI dials |
| `the-shack.html` | Costume shack, crepe paper on cardboard | Inbox before/after switch · fill-the-chairs week · chat with booking tickets |
| `midnight-bay-street.html` | Parade after dark | Drum-pad patient scenarios · desk hours vs. message traffic · drum-pad ROI |

Preview: `python3 -m http.server 8080` from this folder, then open a page.
All chats and numbers are simulations; nothing is sent.
